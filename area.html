How it works

Area uses the coordinate (shoelace) method: 2A = Σ (E₁·N₂ − E₂·N₁) around the figure. The last point is closed back to the first automatically, so you don't need to repeat it. If you do, it's only counted once.

Points have to be in order around the boundary, either direction. If two courses cross each other, the figure is a bow-tie and the area is wrong, so you'll get a warning.

Acres are square feet ÷ 43,560. Areas are plane (grid) areas. For State Plane coordinates, divide by the combined scale factor squared to get ground area.
